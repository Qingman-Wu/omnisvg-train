Scalable Vector Graphics (SVG) offer a compact, resolution-independent, and semantically editable representation for visual content, making them indispensable in graphic design, web development, and user interface prototyping. Unlike raster images, SVGs describe visual elements as structured sequences of drawing commands—paths, curves, and fills—forming what can be viewed as a visual program. Recent autoregressive approaches cast SVG generation as next-token prediction over tokenized SVG sequences, achieving impressive results on simple icons and shapes [OmniSVG, SVGen, InternSVG]. However, as structural complexity grows—more parts, deeper layering, and richer spatial relationships—these models increasingly struggle to produce coherent outputs.

We observe three systematic failure modes in existing text-to-SVG decoders (Figure 1). First, *part omission*: structurally complex components such as limbs, accessories, or background elements are silently dropped. Second, *layout drift*: spatial arrangements degrade progressively over long generation sequences, causing misaligned or disproportionate compositions. Third, *repetitive strokes*: the decoder falls into degenerate loops, producing redundant paths that add visual noise without structural content. We trace these failures to a common root cause: the absence of *visual grounding* during autoregressive decoding. Text prompts specify *what* to generate but provide no structural evidence for *how* to compose the visual program. As the decoder advances through hundreds or thousands of SVG tokens, it must rely entirely on its own hidden state to maintain global coherence and local precision—a burden that text conditioning alone cannot sustain. This observation leads us to recast text-to-SVG generation as a problem of *grounded visual-program synthesis*: the decoder should have access to structured visual evidence that guides both the overall composition and the fine-grained details of each generation step.

To this end, we introduce *Fetch, Frame, and Focus*, a retrieval-augmented framework that supplies the frozen autoregressive decoder with compositionally structured visual evidence at every generation step. Given a text prompt, the **Fetch** stage retrieves the top-$K$ most similar SVGs from a large corpus via cross-modal similarity search and decomposes each into semantically coherent part groups through spatial clustering. The retrieved references are then processed into two complementary memory forms. The **Frame** stage compresses the full reference images into a *Panoramic Memory* via a Q-Former encoder, capturing global scene context—the overall layout, part inventory, and spatial arrangement—in a fixed set of 32 learnable query tokens. The **Focus** stage encodes each decomposed part group independently through a shared-weight group-wise encoder, producing a bank of 12 spatially tagged *Spotlight Memory* slots, from which a lightweight dot-product router selects the single most relevant entry conditioned on the current decoder hidden state. The panoramic memory provides persistent, broadcast-style scene context, while the spotlight memory offers on-demand, selective access to fine-grained structural detail—each decoding token retrieves only the reference evidence it needs.

Through systematic ablation across 17 experimental configurations, we distill three design principles for effective visual grounding in SVG generation. (i) *Structurally decomposed rather than flattened*: encoding reference information as semantically grouped parts with spatial tags outperforms directly attending to flat token sequences or prepending visual prefixes. (ii) *Selectively accessed rather than uniformly broadcast*: routing detail memory via a top-$k$ selector with confidence modulation outperforms uniform attention over all detail slots. (iii) *Injected in late decoder layers rather than early ones*: concentrating memory injection in the last four of 28 decoder layers, where fine-grained spatial decisions are made, is more effective than uniform or early-layer injection. The entire grounding module adds only 285M trainable parameters (3.7\% of the frozen 7.6B backbone), requires no multimodal retraining of the base model, and is architecture-preserving—readily transferable to other autoregressive generation backbones.

We summarize our contributions as follows:

- We identify the absence of visual grounding during decoding as a central bottleneck of autoregressive text-to-SVG generation, manifesting as part omission, layout drift, and repetitive strokes in structurally complex outputs.

- We propose Fetch, Frame, and Focus, a retrieval-augmented framework that transforms retrieved reference SVGs into two complementary forms of visual evidence—a panoramic memory for global scene context and a bank of spotlight memory slots for selective, step-specific structural detail—injected into the frozen decoder through lightweight late-layer modules.

- Through systematic ablation, we derive three generalizable design principles: reference information should be structurally decomposed, selectively accessed, and injected in late decoder layers.

- We conduct comprehensive evaluation against 21 methods across three categories—optimization-based methods, autoregressive text-to-SVG models, and general-purpose LLMs/VLMs including GPT-5.4 and Claude-4-Sonnet—demonstrating consistent improvements in generation quality while adding merely 3.7\% trainable parameters to the frozen backbone.
